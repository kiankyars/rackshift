# Contributing

This repository is the Qodo evidence trail for the Agent Harness Hackathon.

1. Branch. Do not push commits to `main`.
2. Open a pull request with a title that says what changed and a body that says why.
3. Wait for Qodo. If it does not start, comment `/agentic_review`.
4. Fix every valid High-severity finding, or dismiss it in the Qodo thread with a reason.
5. Push, then run `/agentic_review` again so the follow-up is on the same PR.
6. A human merges. The agent never merges.
